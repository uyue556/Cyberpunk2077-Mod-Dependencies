# Cyberpunk 2077 MOD 前置组件备份

此仓库备份从本机《赛博朋克 2077》安装目录中提取的前置组件文件，并非官方发行包。文件保留相对游戏根目录的路径；复制到其他安装目录前请确认游戏及组件版本兼容并备份原文件。

- RED4ext：日志记录版本 1.31.0
- Cyber Engine Tweaks：日志记录版本 1.38.0
- ArchiveXL：日志记录版本 1.28.0
- TweakXL：日志记录版本 1.12.0
- Codeware：日志记录版本 1.21.0
- redscript：本机编译器文件的版本及归属尚未确认，未包含在压缩包中

此备份排除本机日志、个人配置、其他 MOD、缓存和游戏本体。CET 的加载器和 redscript 的完整依赖尚未确认，因此不能保证直接复制后即可正常工作；请按需参考各组件官方安装说明。REDmod 不包含在内。

各组件保留其随附的版权及第三方许可声明，各组件适用其各自的许可条款。
